# 0.4.3 设置页与独立助手 UI 候选

设置页分为备份、任务与恢复、帮助与诊断三个分区，使用 DSH 语义颜色与继承字体，支持主题、字号、窄窗口、键盘和 reduced-motion；不依赖构建哈希 CSS 类名。

创建完整备份是唯一突出的主操作。退出说明、任务历史、依赖详情和专家功能按层级展开。私人 ZIP 未加密警告始终可见，文件完整性成功与恢复业务验收分开表述。

页面加载时只读显示当前 Profile、任务锁快照、最近五项任务及保留的依赖问题。不运行新的依赖预检查，不判断任务存活，不创建或删除锁。快照不能作为解锁证明；检查和人工确认仍使用原有安全恢复流程，服务端重新核验证据。

兼容性提示只读取实际任务记录；没有记录时明确未检查，不将历史问题数硬编码为本次结果。UI 改版不解决既有浏览器 peer 阻塞。

独立助手继续使用 WinForms，仅为阶段导航、图标、进度和按钮局部自绘；没有新增 UI 运行时。向导依次显示退出、环境检查、打包、校验和完成。外观与字号收进菜单，详情默认折叠，高对比度优先；系统关闭 UI 动效时停止动画。

真实计数与不定进度保持区分。失败终态缺少阶段字段时，显示“失败阶段未记录”和最后观察到的阶段，不猜测或固定标红环境检查。终态重置计数时保留最后观察数并注明；没有可靠计数则显示未知。文件校验成功始终与恢复业务验收分开。

UI 模块不负责退出确认、进程检测、文件读锁、协调器生命周期、ZIP 验证或锁退役，这些原有流程保留在原模块中。视图不自动退出或重启 DSH。

自动无障碍检查只证明结构、控件属性和规则检查结果，不能替代实际屏幕阅读器语音验收或正式 DSH 内人工视觉验收。本候选不代表已部署。
